# مواصفات منصة محلات

مرجع تنفيذ منصة محلات للمبرمج: قواعد العمل والرسوم، وصفحات الواجهات الأربع بمعايناتها، والمتطلبات بمعايير قبولها. موقع ثابت لا يحتاج أمر بناء: `index.html` و`assets/` في الجذر، ومنشور على mahallatv2.hamzanasr.com.

- **`index.html`: المواصفات فقط.** 233 متطلباً، و93 صفحة لكل منها معاينة وعناصر وإجراءات وحالات، والقيم المرنة، والأدوار والصلاحيات، وتعريف المؤشرات. وفي آخرها الأسئلة المفتوحة للمالك.
- **`prd.md`:** نسخة نصية من المواصفات للقراءة بالأدوات.

كل قاعدة مكتوبة في مكان واحد: المتطلب هو المرجع، والأرقام في المتطلب وجدول «القيم المرنة»، والصفحات والملاحق تشير إليهما.

## البناء
```bash
cd tools
python build.py          # يكتب index.html وassets/ وprd.md في جذر المستودع
python verify4.py        # يتحقق أن كل متطلب وصفحة وإعداد ورقم من ملف المالك موجود
```
يحتاج Python 3 مع `beautifulsoup4` و`lxml`.

## المصادر
| الملف | الدور |
|---|---|
| `tools/newprd.json` | ملف المالك (المتطلبات والصفحات والإعدادات والتقارير والمخططات) |
| `tools/b4_decisions.py`، `tools/b4_decisions3.py`، `tools/b4_decisions4.py` | قرارات المالك، تُكتب في نص المتطلبات عند البناء |
| `tools/ux/out2/` | مواصفات كل صفحة (العناصر والإجراءات والحالات والتحقق والصلاحيات) |
| `tools/ux/out/` | الصفحات الجديدة وبياناتها الأساسية |
| `tools/ux/mocks/` | معاينات الصفحات (و`_2` لحالة ثانية)؛ صوّر أي معاينة بـ `python ux/shot.py C09` |
| `tools/ux/notes_review.json`، `tools/ux/questions.json` | الأسئلة المفتوحة |
| `tools/qa/fixes.json` | التصحيحات اللغوية المطبَّقة على نص المتطلبات |
