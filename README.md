# مواصفات منصة محلات

مرجع تنفيذ منصة محلات للمبرمج: قواعد العمل والرسوم، وصفحات الواجهات الأربع بمعايناتها، والمتطلبات بمعايير قبولها. موقع ثابت لا يحتاج أمر بناء: `index.html` و`assets/` في الجذر، ومنشور على mahallatv2.hamzanasr.com.

- **`index.html`: المواصفات فقط.** 240 متطلباً، و93 صفحة لكل منها معاينة وعناصر وإجراءات وحالات، والقيم المرنة، والأدوار والصلاحيات، وتعريف المؤشرات. وفي آخرها الأسئلة المفتوحة للمالك.
- **`en/index.html`:** الموقع نفسه بالإنجليزية (mahallatv2.hamzanasr.com/en/)، وزر «English / العربية» أعلى الصفحتين يبدّل اللغة في الموضع نفسه.
- **`prd.md`:** نسخة نصية من المواصفات للقراءة بالأدوات.
- **`prd.en.md`:** النسخة الإنجليزية من `prd.md` (English version of the specification). مترجمة يدوياً، ولا يكتبها `build.py`؛ تُحدَّث عند تغيير المواصفات.

كل قاعدة مكتوبة في مكان واحد: المتطلب هو المرجع، والأرقام في المتطلب وجدول «القيم المرنة»، والصفحات والملاحق تشير إليهما.

## البناء
```bash
cd tools
python build.py          # يكتب index.html وassets/ وprd.md في جذر المستودع
python verify4.py        # يتحقق أن كل متطلب وصفحة وإعداد ورقم من ملف المالك موجود
```
يحتاج Python 3 مع `beautifulsoup4` و`lxml`.

## المصادر
| الملف | الدور |
|---|---|
| `tools/newprd.json` | ملف المالك (المتطلبات والصفحات والإعدادات والتقارير والمخططات) |
| `tools/b4_decisions.py`، `tools/b4_decisions3.py` … `tools/b4_decisions10.py` | قرارات المالك، تُكتب في نص المتطلبات عند البناء (الإصدار 4.11: الجولة التاسعة) |
| `tools/b4_annex.py`، `tools/b4_annex9.py` | الملاحق: حالات الطلب والتوزيع والأدوار والمؤشرات، والقيم الافتراضية المضافة في 4.11، وملحقا PAY-005 (دليل الحسابات) وMER-037 (صلاحيات طاقم التاجر) |
| `tools/b4_terms6.py` و`tools/b4_terms6_*.py` | توحيد المصطلحات وفق المسرد (الجولة السادسة): أسطر متطلبات كاملة وبيانات صفحات |
| `docs/GLOSSARY.md`، `docs/adr/` | المسرد الموحّد للمصطلحات وما يُتجنّب منها، وقرارات المعمارية |
| `tools/ux/out2/` | مواصفات كل صفحة (العناصر والإجراءات والحالات والتحقق والصلاحيات) |
| `tools/ux/out/` | الصفحات الجديدة وبياناتها الأساسية |
| `tools/ux/mocks/` | معاينات الصفحات (و`_2` لحالة ثانية)؛ صوّر أي معاينة بـ `python ux/shot.py C09` |
| `tools/ux/notes_review.json`، `tools/ux/questions.json` | الأسئلة المفتوحة: «open» و«settled» في notes_review تُعرض في «أسئلة مفتوحة» |
| `tools/b4_en.py`، `tools/i18n/en.json` | يبني `en/index.html` من الصفحة العربية بقاموس الترجمة؛ المقطع الجديد غير المترجم يبقى عربياً ويظهر عدده في البناء، واستخرجه بـ `python b4_en.py --missing missing.json` لترجمته |
| `tools/qa/fixes.json` | التصحيحات اللغوية المطبَّقة على نص المتطلبات |
